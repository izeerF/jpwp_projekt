# Firewall Breach

Jest to projekt gry tower defense napisanej w javie z wykorzystaniem biblioteki javafx oraz narzedzia maven. Glownym celem gracza jest obrona serwerow przed atakiem wrogow nadciagajacych z internetu.

## wymagania i uruchamianie

aby uruchomic gre, wymagana jest java w odpowiedniej wersji oraz zainstalowany maven.
nalezy otworzyc terminal w glownym folderze projektu (tam, gdzie znajduje sie plik `pom.xml`) i wpisac ponizsze polecenie.

`mvn javafx:run`

lub za pomoca extension do vscode kliknac w pliku main nad funkcja main `run`
